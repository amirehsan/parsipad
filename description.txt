ParsiPad - AI-Powered Persian ↔ English Translator

The most powerful Persian-English translator for Chrome! Choose your favorite AI provider (Claude, Gemini, or ChatGPT), bring your own API key, and enjoy seamless translations with advanced learning features.

KEY FEATURES:

🤖 Multi-AI Provider Support
Choose between Claude (Anthropic), Gemini (Google), or ChatGPT (OpenAI). Use your own API key for complete privacy.

🖱️ Block Translate
Rest the pointer on any paragraph, post, or heading for about half a second and a small icon appears at its corner. Click it and the Persian is inserted directly underneath, so the original stays in place and both can be read together. Hovering a heading translates the whole section, interleaving each paragraph's Persian beneath it instead of one block of text at the end. Colors are drawn from the page behind it, so it stays legible on dark sites and light ones alike. Press Alt+B to translate from the keyboard. Works on any site with no setup, and is on by default (turn it off anytime in Settings).

📸 Screenshot Region Translate
Select any area of a webpage, even text that is not selectable, like a banner or an image. Press Alt+S or right-click and choose "Screenshot and Translate," then drag to select the region and let AI extract and translate what it finds.

🖼️ Image Translation
Extract and translate text from images using AI-powered OCR. Perfect for screenshots, photos of signs, menus, or documents.

📚 Grammar Learning
Learn while you translate! Enable grammar explanations to understand word order, verb conjugations, and idiomatic expressions. Click "Learn More" to access a dedicated grammar page with:
• Detailed explanations in your target language
• Multiple examples for each grammar point
• Compare & contrast between languages
• Interactive quizzes to test your understanding
• Save grammar lessons to favorites

✍️ Text Polishing
Get 3 versions of your text: Professional, Conversational, and Concise. Regenerate any variant for fresh alternatives.

📖 Dictionary Lookup
Look up words with definitions, phonetics, synonyms, and antonyms. Press Alt+D or right-click any word.

⭐ Favorites & Practice
Star your best translations to save them. Practice deals your favorites as flashcards, a few at a time: each card shows the saved translation, and flipping it reveals the original. Flip with Space or Enter, move with the arrow keys, and choose 5 to 30 cards per session in Settings. Open it from the side panel or the Library.

🕐 New Tab
Every new tab shows one saved word in large Persian or English type, with the time and a greeting in both languages above it. Click it to reveal the original. Your bookmarks live in a searchable drawer that opens with "/", and your most visited sites can appear as tiles if you switch them on, with icons read from your browser's own cache and never sent anywhere. Turn it off in Settings to get Chrome's own New Tab back.

🗂️ Library
Everything you translate, polish, or look up lives in one searchable Library with History, Favorites, and Lessons tabs. Filter by type or direction, delete an entry and bring it back with Undo, and reopen a saved grammar lesson with no new request to your provider.

📄 Document Translation
Drop, choose, or paste a TXT file into Doc & Image and translate the whole document with progress tracking. The same drop zone takes images.

🌐 Full Page Translation
Translate entire webpages with one click! Right-click and select "Translate this page" or press Alt+P. Toggle between original and translated text with the floating button. Persian text uses Vazirmatn font for optimal readability.

🎯 Quick Access
• Selection popup: Select text and click floating icons
• Keyboard shortcuts: Alt+T (translate), Alt+D (dictionary), Alt+P (page), Alt+S (screenshot), Alt+B (block translate)
• Right-click menu: Translate, polish, dictionary, translate page, or screenshot translate from any webpage

💾 Data Backup
Export and import your favorites, history, and cache to JSON for easy backup or device migration.

📊 Analytics Dashboard
Track your API usage and estimated cost per provider, broken down by action type, with usage trends over 7 days, 30 days, or all time. Export the data as JSON whenever you want it.

🌙 Dark Mode
Beautiful dark theme that syncs with your system preferences.

🌐 Bilingual Interface
Full English and Persian (فارسی) interface support.

PRIVACY-FIRST:
• No data collection
• No analytics or tracking
• All data stored locally on your device
• Direct API calls to your chosen provider
• Open source

GETTING STARTED:
1. Install the extension
2. Get an API key from Claude, Gemini, or ChatGPT
3. Enter your API key in Settings
4. Start translating!

Perfect for students, professionals, language learners, and anyone who needs accurate Persian-English translations with the power of modern AI.

Free to use - you only pay for your own API usage (typically just a few cents per day).
