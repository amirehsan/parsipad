Everything You Need to Translate

Powerful features designed to make Persian-English translation seamless and efficient.

NEW

Multi-AI Provider

Choose your preferred AI: Claude (Anthropic), Gemini (Google), or ChatGPT (OpenAI). Switch anytime in settings.

NEW

Screenshot Translate

Select any area on a webpage to translate text from images, banners, or non-selectable content. Press Alt+S to start.

NEW

Grammar Learning

Interactive grammar lessons with quizzes, text-to-speech, transliteration (Pinglish), and register badges. Master grammar while translating.

Text Polishing

Get three versions of your text: Professional, Conversational, and Concise. Perfect for any situation.

Dictionary Lookup

Look up any word to see definitions, phonetics, synonyms, and antonyms. Press Alt+D or right-click.

Selection Popup

Select any text and instantly see floating icons for Translate, Polish, or Dictionary lookup. No right-click needed.

NEW

Favorites

Star your best translations and polished text to save them. Access your favorites anytime from a dedicated page.

NEW

New Tab Dashboard

Two-column new tab page with flashcards and Chrome bookmark browser. Search and filter bookmarks in a folder tree. Review vocabulary with interactive flashcards side by side.

NEW

Full Page Translation

Translate entire webpages with one click. Press Alt+P or right-click. Toggle between original and translated text.

Document Translation

Upload TXT files and translate entire documents with progress tracking and download. Cancel anytime.

NEW

Analytics Dashboard

Track your API usage and estimated costs per provider. View action breakdowns, time-based trends, and export data as JSON.

How It Works

Get started in three simple steps. You'll be translating in no time.

Install

Add ParsiPad to Chrome from the Web Store in one click. It's completely free.

Configure

Choose your AI provider and enter your API key. Get keys from Anthropic, Google, or OpenAI.

Translate

Select text anywhere and press Alt+T or right-click to translate instantly.
