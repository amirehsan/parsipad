# Chrome Web Store Listing for ParsiPad

## Extension Name
ParsiPad - Persian English Translator

## Short Description (132 chars max)
Hover any paragraph to translate it. Screenshot translate, grammar lessons, flashcards. Claude, Gemini, or ChatGPT

## Detailed Description

ParsiPad is a powerful AI-powered translation extension that makes Persian-English translation seamless and intelligent.

Version 3.4.0:
• Library - History, Favorites and saved grammar Lessons in one page, with search, filters, and Undo on delete
• Practice - flashcards from your favorites, in the side panel or a tab
• Saved grammar lessons reopen with no new request to your provider
• The New Tab page is gone, along with the bookmarks and most-visited permissions it needed

🖱️ **Block Translate** (NEW!)
Read a page in Persian without leaving it:
• Rest the pointer on any paragraph, post, or heading for about half a second and a small icon appears at its corner
• Click the icon and the Persian is inserted directly underneath, leaving the original in place so both can be read together
• Only appears when the pointer rests, not when it merely crosses a block, so ordinary browsing stays quiet
• Never offered on text already in your own language
• Hovering a heading translates the whole section, with each paragraph's Persian interleaved beneath it rather than one block of text at the end
• Colors are drawn from the page behind the translation, so it stays legible on dark and light sites alike
• Alt+B translates the block at the keyboard focus, for anyone not using a pointer

🤖 **Choose Your AI**
Pick your preferred AI provider:
• Claude (Anthropic) - Excellent for nuanced translations
• Gemini (Google) - Fast and efficient
• ChatGPT (OpenAI) - Versatile and reliable
Switch providers anytime in Settings!

🌐 **Full Page Translation** (NEW!)
Translate entire webpages instantly:
• Right-click "Translate this page" or press Alt+P
• Smart chunking for reliable translation
• Progress overlay with real-time status
• Toggle button to switch between original/translated
• Vazirmatn font for beautiful Persian text
• Cancel anytime

🎓 **Grammar Learning**
Master grammar while you translate:
• Dedicated grammar learning page with detailed explanations
• Interactive quizzes with educational feedback for each answer
• Text-to-Speech - hear correct pronunciation
• Transliteration - read Persian script phonetically (Pinglish)
• Register badges show formal vs informal usage
• Compare & Contrast sections for English/Persian differences
• Common mistakes section to avoid typical errors
• Save grammar lessons to Favorites for review

📸 **Screenshot Region Translate** (NEW!)
Translate text from any area on a webpage:
• Press Alt+S or right-click "Screenshot & Translate"
• Drag to select region with crosshair cursor
• AI extracts and translates text from the captured area
• Perfect for images, banners, and non-selectable text

🖼️ **Image Translation**
Extract and translate text from images:
• Upload images or paste from clipboard
• OCR extracts text automatically
• Supports JPG, PNG, WebP (up to 5MB)

✨ **Smart Text Polishing**
Not just translation! Polish your text in three styles:
• Professional - formal, business-ready text
• Conversational - natural, friendly tone
• Concise - shorter, to-the-point version
• Regenerate any variant for fresh alternatives

📖 **Dictionary Lookup**
Look up any word to get comprehensive lexical information:
• Definitions with example sentences
• Phonetic transcription (IPA)
• Synonyms and antonyms
• Persian/English translation
• Right-click or press Alt+D to look up instantly

📄 **Document Translation**
Translate entire documents with ease:
• Upload TXT files directly
• Progress tracking with chunk indicator
• Cancel anytime during long translations
• Download translated file when complete

⭐ **Favorites & Practice**
Save your best translations and learn vocabulary:
• Star any translation, polished text, or grammar lesson
• Practice deals your favorites as flashcards, from the side panel or the Library
• Flip cards to reveal the original text
• Navigate with keyboard shortcuts: arrows to move, Space or Enter to flip, C to copy
• Choose 5 to 30 cards per session in Settings

🎯 **Multiple Ways to Use**
• Select text and use the floating popup
• Right-click context menu for translation, polish, dictionary, page, or screenshot translate
• Keyboard shortcuts: Alt+T (translate), Alt+D (dictionary), Alt+P (page), Alt+S (screenshot), Alt+B (block translate)
• Popup and side panel with three modes: Translate, Polish, and Doc & Image

📚 **Library**
• One place for History, Favorites, and saved grammar Lessons, in tabs
• Search, filter by translation, dictionary, or polish, and filter by direction
• Grouped by Today, This week, and Earlier
• Delete an entry and bring it back with Undo
• Reopen a saved grammar lesson with no new request to your provider

💾 **Data Backup**
Keep your data safe and portable:
• Export favorites, history, and cache to JSON
• Import with merge or replace strategy
• Selective export - choose what to include
• Easy device migration

🎨 **Beautiful Design**
• Clean, modern interface
• Dark mode support (syncs with system preference)
• Full RTL support for Persian text
• Smooth animations
• Bilingual UI (English/Persian)

⚙️ **Customizable Settings**
• Choose your AI provider (Claude, Gemini, ChatGPT)
• Set how many flashcards a Practice session holds (5 to 30)
• Export and import your data
• Control dictionary translation directions (EN→FA, FA→EN)
• Choose UI language
• Manage translation cache
• View usage statistics

🔒 **Privacy First**
• Your API keys stay on your device
• No data collection or tracking
• All history stored locally
• Offline caching for instant repeat lookups

**How to Use:**
1. Get an API key from your preferred provider:
   • Claude: console.anthropic.com
   • Gemini: aistudio.google.com/apikey
   • ChatGPT: platform.openai.com/api-keys
2. Select your provider in Settings
3. Enter your API key and save
4. Start translating!

Powered by Claude, Gemini, and ChatGPT for the highest quality translations.
