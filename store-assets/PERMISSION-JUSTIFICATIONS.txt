ParsiPad - Chrome Web Store permission justifications
Paste these into Privacy practices > "Permission justification" for each item.

====================================================================
The other declared permissions, for reference
====================================================================
storage
  Stores the user's own settings, their saved favorites, translation history
  and the local translation cache, using chrome.storage.local. All of it stays
  on the user's device.

contextMenus
  Adds ParsiPad's right-click entries ("Translate selection", "Polish text",
  "Look up in dictionary") so the user can act on selected text.

sidePanel
  Lets the user open ParsiPad in Chrome's side panel, from a button in the
  popup or from the right-click menu, so it stays open beside the page while
  they browse. The panel is the same packaged ParsiPad interface as the popup.
  It is opened only by the user's click and adds no new data access.

activeTab + scripting
  Used to read the text the user selected and to show ParsiPad's translation
  box on the page, only on the tab the user invoked ParsiPad on, and only in
  response to that action.

Host permissions (api.anthropic.com, generativelanguage.googleapis.com,
api.openai.com)
  ParsiPad sends the text the user asked to translate directly to whichever
  AI provider the user configured, using the user's own API key. These three
  hosts are the providers' API endpoints. There is no ParsiPad server and no
  intermediary: the request goes from the user's browser to the provider they
  chose.

Content script on <all_urls>
  ParsiPad's core feature is translating text the user selects on any page,
  so the content script has to be able to run wherever the user is reading.
  It does nothing until the user acts: it listens for a selection and only
  then offers the translate/polish/dictionary controls. When the user
  selects text, the selection (never text inside form fields, at most 2000
  characters) is passed to ParsiPad's own side panel so it can offer to
  translate it; it never leaves the browser. Page text goes to the user's
  chosen AI provider only when the user asks for a translation. The content
  script injects no code from any remote source.

====================================================================
Data usage disclosures
====================================================================
Remote code: No. Everything executed is packaged in the extension.

Data collected: the text the user explicitly submits for translation is sent
to the AI provider the user configured, with the user's own API key, in order
to perform the translation the user asked for. Nothing else is collected.
ParsiPad operates no server, has no account system, and stores settings,
favorites, history and cache only in the user's local browser storage.

Certifications: data is not sold to third parties; is not used or transferred
for any purpose unrelated to the item's single purpose; and is not used or
transferred to determine creditworthiness or for lending purposes.

Single purpose: ParsiPad is a Persian-English translator. Everything it does
serves translating text between Persian and English and helping the user
learn from those translations.
